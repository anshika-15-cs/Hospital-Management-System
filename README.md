# Hospital Database Management System

Python based, gui driven hospital management system, integrated with MySQL database designed for hospital management and administration

## Features
1. Admin Portal
2. Patient Portal
3. Doctor Portal
4. Database Integration

## Stack
1. Python 3.12 (with tkinter for GUI)
2. MySQL Server
3. mysql-connector-python

## Installation & Setup
1. Clone the repository:

```
git clone https://github.com/anshika-15-cs/Hospital_DBMS-.git

```

2. Install mysql connecter

``` pip install mysql-connector-python ```

3. Setup MySQL with proper tables

    required tables (doctors, patients, appointments) inside a database named hospital_management.

4. Run program

``` python main.py ```
